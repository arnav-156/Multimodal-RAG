## Acceptance limits

The local fixture validation was GPU-assisted and used short generated engineering images/PDF pages. It does not establish handwriting, multilingual, noisy-document or production vision quality. The tested service used context4096, generation cap512 and one sequential source/page at a time with a300second timeout. Provider allocation values are not peak process/system memory; measure representative limits on the intended host.

Generation is probabilistic. Inspect critical content against originals. An already-sent local request is not forcibly recalled by a later cancellation/revocation; subsequent work is blocked by current policy. Identity changes, stale descriptions, failed generation and source/root revocation remain explicit lifecycle outcomes. No source file is silently certified by a declaration of model revision.
