Technical readiness details
Library settings
Explicit scan folders are required in scanner.scan_paths. All settings are shown below as JSON. Secrets are write-only: leave redaction markers intact to preserve them, or use an empty string to remove a secret. Changes are validated before saving.
Changing the database requires editing YAML and restarting. Server host and port changes require a restart. Embedding contract changes require an explicit rebuild with process --force.
Advanced compatibility notes
Compatibility fields: Historical pipeline settings except pipeline.fetch_limit, scanner.home_paths/everything_exe, monitor, embedding.model_path and vllm launch hints, metadata.log_file, logging, vision.max_workers and endpoint max_parallel are retained for old YAML round trips. They do not control scheduling, service launching or logging. Use scanner.scan_paths for folders; provision model services separately. embedding.vllm.api_url/model_name remain active fallback aliases. The int8 scale is fixed at 127. Secrets and existing aliases are preserved when saving.
